# Site logos

Each TM-Exchange site's own logo, as shown in the site-switch menu of every
exchange page. Downloaded once (plain GET), downscaled to 64 px (`<host>.png`). The extension does not fetch any icon at runtime.

| File | Source |
| --- | --- |
| tmnf.exchange | https://account.mania.exchange/img/logos/TMNF.png (256x256) |
| tmuf.exchange | https://account.mania.exchange/img/logos/TMU.png (256x256) |
| nations.tm-exchange.com | https://account.mania.exchange/img/logos/TMN.png (256x256) |
| sunrise.tm-exchange.com | https://account.mania.exchange/img/logos/TMS.png (256x256) |
| original.tm-exchange.com | https://account.mania.exchange/img/logos/TMO.png (256x256) |

The logos belong to their owners (Nadeo / Ubisoft, ManiaExchange); they are used only to mark which exchange a list entry belongs to.

Copied unchanged into Legacy Randomizer from TMX-Downloader 2.1 (`icons/sites`); embedded in the plugin DLL by `assets/make_site_logos.py`. The plugin does not fetch any logo at runtime either.
